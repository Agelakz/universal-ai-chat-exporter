# Contributing

Thank you for contributing to Universal AI Chat Exporter.

1. Fork the repository.
2. Create a focused branch from the default branch.
3. Make a small, documented change.
4. Open `chrome://extensions`, enable Developer mode, and load the repository folder with **Load unpacked**.
5. Test on both ChatGPT and Gemini where relevant, including the affected export formats.
6. Open a pull request describing the provider, change, and tests performed.

Never commit real or private conversations as fixtures, screenshots, logs, or examples. Use synthetic content only. Do not include cookies, tokens, session data, or credentials in an issue or pull request.

When reporting a broken provider selector, include the provider, page type, browser version, extension version, observed behavior, expected behavior, and a sanitized DOM description if useful. Do not submit account data or full conversation content.
