# Privacy Policy

Universal AI Chat Exporter processes the currently open conversation locally in the browser.

- The project operates no server or backend.
- No analytics or telemetry is collected.
- Cookies, authentication tokens, sessions, and credentials are not read or collected.
- Conversation data is not sold, shared, or sent to third parties.
- An export file is generated only after the user clicks the export button.
- Generated files are downloaded directly to the user's device through the browser download feature.

The extension reads only conversation content already rendered on the supported page so it can create the requested export. Review the source code in this repository to verify this behavior.
