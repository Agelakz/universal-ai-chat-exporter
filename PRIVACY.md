# Privacy Policy

Universal AI Chat Exporter processes the currently open conversation locally in the browser.

- The project operates no server or backend.
- No analytics or telemetry is collected.
- Cookies, authentication tokens, sessions, and credentials are not read or collected.
- Conversation data is not sold, shared, or sent to third parties.
- Conversation responses may be read from the supported provider page using the user's existing browser session; credentials are never copied into the export.
- Imported JSON capsules are parsed and validated locally and are not uploaded.
- Selected conversation content is written to the clipboard only after the user clicks **Copy for AI**.
- An export file is generated only after the user clicks the export button.
- Generated files are downloaded directly to the user's device through the browser download feature.

The extension reads the open conversation from a provider response when available and otherwise falls back to content rendered on the page. Review the source code in this repository to verify this behavior.
